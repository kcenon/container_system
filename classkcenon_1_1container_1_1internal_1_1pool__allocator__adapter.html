Detailed Description

template<typename T>
class kcenon::container::internal::pool_allocator_adapter< T >

STL-compatible allocator adapter that routes allocations through pool_allocator.

Satisfies the C++ AllocatorAwareContainer and Allocator named requirements so it can be used as the template argument to any STL container.

Example:

std::vector<int, kcenon::container::internal::pool_allocator_adapter<int>> v;
v.reserve(16);
v.push_back(42);

TElement type. Must be destructible.

Allocate storage for n objects of type T.

Routes through the thread-local pool_allocator singleton, which selects the small, medium, or heap path based on total byte size. Throws std::bad_alloc on failure to mirror std::allocator behaviour.

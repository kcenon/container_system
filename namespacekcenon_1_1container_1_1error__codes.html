Detailed Description

Standardized error codes for container operations.

Error codes are negative and organised into sub-bands within common's reserved container_system range [-499, -400]:

  • -400 to -409: Value operations
  • -410 to -419: Validation
  • -420 to -429: Serialization
  • -430 to -439: Resource
  • -440 to -449: Thread safety

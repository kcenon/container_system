Detailed Description

Primary C++20 module for container_system.

This is the main module interface for the container_system library. Container system is a small codebase, so it's implemented as a single module without partitions.

Usage:

import kcenon.container;
using namespace kcenon::container;
value_container container;
container.set("name", std::string("value"));
container.set("count", 42);
auto result = container.serialize();

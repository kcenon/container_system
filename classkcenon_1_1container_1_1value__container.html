STL Iterator Support

Provides Standard Library-compatible iteration over container values

Satisfies the STL iterator requirements so that range-based for loops, standard algorithms, and iterator-based utilities (std::distance, std::advance, std::reverse, ...) work directly on value_container.

The iterator delegates to the underlying std::vector<optimized_value> iterator. That alias satisfies std::contiguous_iterator (and therefore std::random_access_iterator, std::bidirectional_iterator, and std::forward_iterator) per [vector.iterators]. The public type aliases below expose this as a standard container interface.

value_container container;
for (const auto& val : container) {
// Process each optimized_value
}
auto it = std::find_if(container.begin(), container.end(),
[](const auto& v) { return v.type == value_types::int_value; });
// Bidirectional traversal:
for (auto rit = container.rbegin(); rit != container.rend(); ++rit) {
// Process values in reverse
}
